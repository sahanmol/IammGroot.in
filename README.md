# IamGroot.in - Artisanal Bakery & Patisserie 🍞🌱

A modern, high-end, responsive web application for **IamGroot.in** built with React, Vite, and Vanilla CSS.

---

## ✨ Features

- **Artisanal Menu**: Filterable catalog (Breads, Pastries, Cakes, Beverages, Vegan & Gluten-Free) with instant search and detail modals.
- **Bespoke Cake Builder**: Interactive 4-step custom celebration cake designer with real-time price estimation.
- **Order Cart Drawer**: Interactive sliding cart drawer with quantity adjustments, store pickup vs. express delivery switch, tip selector, and instant receipt generation.
- **Our Story & Craftsmanship**: Highlighting 36-hour slow-fermentation sourdough and organic grain milling heritage.
- **Guest Reviews**: Interactive customer review display and review submission form.
- **Store Info**: Operating hours, address, call-to-order CTA, and newsletter subscription.

---

## 🛠 Tech Stack

- **Frontend Framework**: React 18 + Vite
- **Styling**: Vanilla CSS (CSS Variables, Glassmorphism, Micro-animations)
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Playfair Display* & *Plus Jakarta Sans*)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
